# 单通道语音增强：贝叶斯估计方法的系统实现与对比

从零实现一条完整的语音增强方法链，从 1979 年的谱减法到 2001 年的 OM-LSA。
除 NumPy / SciPy / Matplotlib 外无第三方依赖，全部算法手写。

**这个项目的主轴不是"实现了哪些算法"，而是：不同的先验假设和代价函数如何导出不同的估计器，以及每削弱一个假设需要付出什么代价。**

## 方法链

所有方法共享同一个骨架：

```
波形 → STFT → [估计增益 G] → 乘上去 → ISTFT → 波形
                    ↑
              唯一变化的地方
```

四十年来变的只有中括号里那一步。

| 方法 | 增益 | 核心思想 | 年份 |
|---|---|---|---|
| 谱减法 | `G = max(1 - Pn/Px, β)` | 功率谱直接相减 | Boll 1979 |
| 维纳滤波 | `G = ξ/(1+ξ)` | 复系数域 MMSE | Wiener 1984年 |
| MMSE-STSA | 含修正贝塞尔函数 I₀, I₁ | 幅度域 MMSE | Ephraim & Malah 1984 |
| MMSE-LSA | `G = ξ/(1+ξ)·exp(½E₁(ν))` | 对数幅度域 MMSE（感知加权） | Ephraim & Malah 1985 |
| OM-LSA | `G = G_LSA^p · G_min^(1-p)` | 二状态模型 + 语音存在概率 | Cohen 2001 |

配套模块：

- **先验信噪比估计**：判决引导法，`ξ_t = α·G²_{t-1}·γ_{t-1} + (1-α)·max(γ_t-1, 0)`
- **噪声功率谱估计**：最小值统计（Martin 2001），滑动窗内取平滑功率的最小值 + 偏差补偿

## 实验结果

**测试条件**：自录真实语音（13 秒，基频约 109 Hz，原始 SNR 30.2 dB），
加粉噪声至 5 dB SNR。STFT 配置 25 ms / 10 ms / 512 点。

| 方法 | 输出 SNR (dB) | 相对带噪 |
|---|---|---|
| 带噪 | 5.00 | — |
| 谱减法 | 6.58 | +1.58 |
| 维纳 + 判决引导 | 8.41 | +3.41 |
| MMSE-STSA | 7.91 | +2.91 |
| MMSE-LSA | 8.28 | +3.28 |
| **OM-LSA** | **8.46** | **+3.46** |
| IRM 理想掩蔽（oracle 上限） | 13.93 | +8.93 |

三点观察：

1. **排序与文献一致**：谱减法明显垫底，OM-LSA 最优，STSA 略低于 LSA。
   在合成信号上得不到这个排序（维纳反而最高），换真实语音后才浮现。
2. **后四种仅差 0.5 dB**。它们的真实差别主要在听感（摩擦音保留、残留噪声自然度），
   不在 SNR。这也是本项目坚持人耳抽听的原因。
3. **距离 IRM 上限仍有 5.5 dB**，这是数据驱动方法的空间。

> **关于 IRM oracle**：IRM 需要干净语音才能计算，现实中不可得。
> 故意"作弊"算出来，是为了测出方法的性能上限——
> 知道天花板在哪，才知道还剩多少改进空间。

## 踩过的三个坑

这一节是本项目最有价值的部分。这些问题都不是读教材能避开的。

### 1. 平滑过头导致语音被误压，SNR 反而低于不处理

最小值统计的平滑系数最初取 `alpha_s = 0.9`，输出 SNR 只有 1.6 dB，
**比不处理（2.35 dB）还差**。

诊断方式是把 SNR 拆成两个维度分别计算：

```python
resid = ISTFT(G * N)   # 噪声分量单独走同一组增益
kept  = ISTFT(G * C)   # 语音分量单独走同一组增益
NR = 10log10(‖N‖² / ‖resid‖²)    # 噪声抑制量，越大越好
SD = 10log10(‖C‖² / ‖kept‖²)     # 语音失真量，越小越好
```

结果 `NR = 15.75 dB`、`SD = 7.63 dB`——**问题不在噪声没压住，而在语音被削掉了**。
进一步检查发现噪声估计整体偏高 5.8 dB，语音段平均增益只有 0.014。

根因：`alpha_s = 0.9` 对应时间常数约 95 ms，而音节间隙只有几帧宽。
平滑过头使滑动窗内的最小值降不到真实噪声底，噪声被系统性高估。
改成 `0.7` 后 SNR 变为 8.24 dB。

**教训**：NR / SD 分维度诊断比单看 SNR 有效得多。
这两个维度分别对应 ITU-T P.835 主观评测中的 BAK 和 SIG。

### 2. 论文给的阈值在自己的数据上失配

实现 OM-LSA 的自适应 `q`（语音不存在的先验概率）时，
按 Cohen 论文取 `ζ_min = -10 dB`、`ζ_max = -5 dB`，
结果语音存在概率 `p` 在静音帧与语音帧几乎相同（0.759 vs 0.786），完全没有区分度。

诊断：打印 ζ 的实际分布，发现落在 −6 ~ 0 dB，
静音帧中位数已达 −5.9 dB，**整体压在论文阈值上限之上**，三个尺度的指标全部饱和为 1。

原因是判决引导的 ξ 在纯噪声区不会趋于零，加上本实现的噪声估计略有偏差，
使 ζ 分布整体上移。改用数据自身的分位数（40% / 85%）定阈值后，
区分度从 0.026 提升到 0.048，与 IRM 的平均差距从 0.229 降到 0.208，增益抖动降低 25%。

**教训**：OM-LSA 的贝叶斯推导很优雅，但它依赖的三个关键量（ξ、噪声功率、q）
全部来自启发式估计，其中两个需要手调阈值。
**推导有多漂亮，参数就有多难调**，而且这些参数互相耦合。

### 3. 截断 ν 却未截断 γ，导致高信噪比下增益塌陷

MMSE-STSA 的增益含 `exp(-ν/2)·I₀(ν/2)`，直接调用 `scipy.special.i0` 在 ν 稍大时即上溢。
正确做法是用指数缩放版 `i0e`，其定义 `i0e(z) = I₀(z)·e^{-z}` 恰好抵消掉指数项。

更隐蔽的 bug：为防溢出把 ν 截断在上限，但 γ 未截断，
导致高信噪比时 `G ≈ ν_clip/γ` 被压到远小于 1，
表现为**输入 SNR 越高、输出 SNR 越差**（10 dB 输入只得到 3.86 dB 输出）。

正确做法是用渐近展开：ν 较大时 `I₀e, I₁e → 1/√(πν)`，
整个式子收敛到维纳增益 `ξ/(1+ξ)`，以 ν = 50 为界分段（相对误差约 1%）。

**教训**：这个 bug 单点测试抓不到，只有**跨参数范围扫描**才会暴露。
回归测试必须覆盖参数区间，而不只是一个工作点。

## 主线：假设的逐层剥离

| 阶段 | 依赖的假设 | 观察到的失效 | 用什么换 |
|---|---|---|---|
| 谱减法 | 逐时频点独立硬判决 | **音乐噪声** | — |
| + 判决引导 | 去掉逐点独立 | 噪声一变化即失效 | 一帧的记忆（状态） |
| + 最小值统计 | 去掉"噪声恒定"与"开头是静音" | 跟踪滞后约等于窗长 | 60 帧历史 + 计算量 |
| + 二状态 (OM-LSA) | 承认语音在时频域稀疏 | q 的估计仍是启发式 | 多尺度上下文 |

**没有免费的午餐**——每削弱一个假设，都要用更多信息或计算去补偿。

音乐噪声的成因值得单独一提：纯噪声区的功率是随机波动的，
谱减法逐点做减法，波动到高于均值的点被保留，形成孤立的时频点，听感是随机音调。
**根源是"用随机量去减随机量，再做硬判决"**。
判决引导通过时间平滑解决它——本实现中增益矩阵沿时间的抖动指标降低约 93%。

## 与贝叶斯估计框架的关系

整条方法链可以统一在同一个框架下：

```
先验 p(S) × 似然 p(X|S) ∝ 后验 p(S|X) → 取某个统计量 → 估计量
```

三种估计器的区别仅在最后一步：ML 取似然最大点，MAP 取后验众数，**MMSE 取后验均值**。

而 Wiener / STSA / LSA 的区别在于 MMSE 准则**作用在哪个量上**：

| 方法 | 最小化 | 结果形式 |
|---|---|---|
| Wiener | `E[(S-Ŝ)²]` 复系数 | 线性估计 |
| MMSE-STSA | `E[(A-Â)²]` 幅度 | 含修正贝塞尔函数 |
| MMSE-LSA | `E[(lnA-lnÂ)²]` 对数幅度 | 含指数积分 |

**对数域的意义**：幅度域对"低估一半"的惩罚只有"高估一倍"的 1/4，
因此优化幅度误差的算法天然倾向压制；对数域对两者惩罚相同，且贴近人耳的对数响度感知。
这一思想延续至今——深度学习损失函数中常见的幂律压缩 `|S|^0.3` 与之同源。

OM-LSA 的几何加权也是推导的自然结果而非拼凑：
估计在对数域进行，对数域的算术平均回到原域即为几何平均。

**局限**：全部推导建立在"语音谱系数服从复高斯"这一假设上，
而真实语音的分布是超高斯的（更尖峰重尾）。
更换先验（Gamma、Laplace）后积分通常不再可解，需要借助近似推断方法。
